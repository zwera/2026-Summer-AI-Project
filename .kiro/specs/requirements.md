# 요구사항 문서: 경찰 실무 AI 법률 지원 시스템

## 프로젝트 개요

현장 경찰관을 위한 AI 기반 법률 지원 시스템으로, 두 가지 핵심 모듈로 구성됩니다.
- **모듈 A**: 판례 검색·요약 AI 봇 (경찰 실무자 특화)
- **모듈 B**: 풍속업소 단속 AI 법률 지원 및 정밀 DB 시스템

---

## 1. 배경 및 문제 정의

### 1.1 판례 검색 영역 (모듈 A)

| ID | 문제 | 설명 |
|----|------|------|
| P-A1 | 기존 서비스의 대상 불일치 | 로앤비, 케이스노트 등은 변호사·판사 등 법률 전문가 대상으로 설계되어 경찰 실무자의 니즈와 맞지 않음 |
| P-A2 | 검색 방식의 장벽 | 실무자는 상황을 말로 설명하나, 기존 서비스는 죄명·법조문을 정확히 입력해야 검색 가능 |
| P-A3 | 시간 제약 | 현장·조서 작성 중 촌각을 다투는 상황에서 전문 판례를 읽을 시간 부족 |
| P-A4 | 법적 리스크 인지 어려움 | 경찰관 본인의 민형사 책임 가능성을 사전에 파악하기 어려움 |

### 1.2 풍속업소 단속 영역 (모듈 B)

| ID | 문제 | 설명 |
|----|------|------|
| P-B1 | 법령 복잡성 | 업종별로 적용 법률이 다르고 벌칙 조항이 세분화되어 현장에서 기억·적용이 불가능에 가까움 |
| P-B2 | AI 환각(Hallucination) 우려 | 일반 AI가 잘못된 법 조항을 안내할 수 있어 기초자료 정도로만 제한적으로 참고 |
| P-B3 | 법적 시비 불안감 | 잘못된 조항 바탕 조치 시 행정소송·법적 시비 발생 가능성에 대한 불안 |

| 구분 | 설명 |
|------|------|
| 주 사용자 | 현장 단속 경찰관, 풍속 단속 전담부서 |

| 특성 | 실무 경험 기반, 법률 전문용어보다 상황 위주 표현 사용 |

## 3. 기능 요구사항

### 3.1 모듈 A - 판례 검색·요약 AI 봇

#### FR-A01: 자연어 상황 질의 검색
- **설명**: 사용자가 현장 상황을 자연어로 입력하면 관련 판례·법조문을 매칭하여 제공
- **입력 예시**: "주취자가 난동을 부리는데 체포해도 되나요?", "미성년자 단독 조사 시 보호자 없이 진행 가능?"
- **출력**: 결론 우선 제시 → 근거 판례는 접이식(collapsible)으로 제공
- **우선순위**: 필수

#### FR-A02: 검색어 자동 보정 (법률 용어 변환)
- **설명**: 일상 표현을 법률 용어로 자동 변환하여 검색 정확도 향상
- **예시**: "집 앞에서 계속 기다림" → "스토킹, 지속적 접근"
- **우선순위**: 필수

#### FR-A03: 업무 시나리오 중심 판례 분류
- **설명**: 형사/민사/행정 분류가 아닌 경찰 직무 단계 기준으로 판례 재분류
- **카테고리**: 현행범체포, 임의동행, 긴급체포, 압수수색, 미란다 원칙 고지, 진술거부권, 가정폭력 초동조치, 음주단속 등
- **비교 제공**: 각 시나리오별 "적법 인정 사례" vs "위법 인정 사례(국가배상·직권남용)" 나란히 비교
- **우선순위**: 필수

#### FR-A04: 단계별 요약 (깊이 선택)
- **설명**: 사용자가 필요에 따라 요약 깊이를 선택할 수 있음
- **단계**:
  - 3줄 요약: 현장 즉시 확인용 (결론 + 핵심 행위 기준)
  - 10줄 요약: 보고서 작성용 (사실관계 + 판단 근거)
  - 전문: 법적 다툼 대비용 (판결문 전문)
- **공통 구조**: ① 사건 개요, ② 법원의 판단, ③ 현장 경찰이 참고해야 할 핵심 포인트
- **표현 방식**: 법률 용어가 아닌 실무 언어로 번역
- **우선순위**: 필수

#### FR-A05: 리스크 하이라이트
- **설명**: 경찰관 본인이 민형사 책임을 질 수 있는 부분을 시각적으로 명확히 표시
- **표시 항목**:
  - 국가배상 인정/기각 여부
  - 직권남용·독직폭행 해당 여부
  - "문제된 행위" vs "적법하다고 본 행위" 구분 배지(badge) 표시
- **우선순위**: 필수

#### FR-A06: 유사판례 유사율 및 최종 인정 죄명 표시
- **설명**: 유사판례에 유사도(%)를 정량화하여 제공하고, 최종 인정 죄명을 함께 표시
- **목적**: 입건 당시 적용 죄명과 실제 재판 결과의 괴리를 미리 확인
- **우선순위**: 높음

#### FR-A07: 사실관계 차이점 하이라이트
- **설명**: 사용자 입력 상황과 매칭된 판례의 사실관계를 비교하여 차이 요소를 하이라이트
- **예시**: 입력은 전치 4주이나 판례는 전치 2주 → 적용 죄명이 달라질 수 있음을 경고
- **우선순위**: 높음

#### FR-A08: 부분 선택 재검토·상세 설명 기능
- **설명**: AI 검토 결과 텍스트를 부분 선택(드래그) 시 재검토/자세히 설명 액션 제공
- **액션**:
  - 재검토(사실 확인): 선택 부분만 근거 판례·법조문을 다시 대조하여 정확성 재확인
  - 자세히 설명: 선택 부분만 풀어서 상세 설명 (관련 판례 추가, 실무 적용 예시 포함)
- **우선순위**: 중간

#### FR-A09: 최신 판례·법령 우선 제공
- **설명**: 현행 법령 기준 판례를 우선 노출하고, 구법 기준 판례에는 배지 표시 및 정렬 순위 하향
- **정렬 로직**:
  1. 판례에서 인용된 법조문 태깅 (법령 마스터 테이블 매칭)
  2. 법령 마스터 테이블에 각 조문의 최신 개정일자·시행일자 관리
  3. 판례 선고일 vs 조문 최신 개정일 비교 → 현행/구법 판별
  4. 최종 점수 = 유사도 점수 × w1 + 법령 최신성 가중치 × w2
- **UI**: 구법 기준 판례 클릭 시 개정 내용 간단 안내 제공
- **우선순위**: 높음

#### FR-A10: 상황 입력 → 타임라인 자동 시각화
- **설명**: 자연어 입력 내용을 분석하여 사건 사실관계를 시간 순서대로 자동 재구성·시각화
- **부가기능**: 각 시점별 행위와 판례상 쟁점 연결 표시
- **활용**: 보고서 작성 시 사실관계 기재에 직접 활용 가능
- **우선순위**: 중간

### 3.2 모듈 B - 풍속업소 단속 AI 법률 지원 시스템

#### FR-B01: 법령 데이터베이스 구축 (약어-법률 매핑)
- **설명**: 단속 현장 약어와 국가 법률 정식 명칭 간 매핑 데이터베이스 구축
- **대상 법률**: 게임산업진흥에 관한 법률, 식품위생법, 음악산업진흥에 관한 법률, 공중위생관리법, 청소년 보호법, 성매매알선 등 행위의 처벌에 관한 법률, 풍속영업의 규제에 관한 법률, 의료법, 체육시설법, 사행행위규제법, 옥외광고물법, 경범죄 처벌법, 감염병예방법
- **우선순위**: 필수

#### FR-B02: 업종별 적용 법조항 분류 체계
- **설명**: 주요 풍속 업종별 단속 법규 및 벌칙·행정처분 관련 핵심 조항 분류
- **업종 구분**:
  - ① 게임제공업 (게임장, PC방 등)
  - ② 유흥주점
  - ③ 노래연습장
  - ④ 일반음식점
  - ⑤ 이용업 / 숙박업
  - ⑥ 목욕장 / 체육 / 크레인
  - ⑦ 변종업소 / 편의점
- **구조**: 업종별 [관련 법률 및 행위 조항] + [벌칙 및 과태료 조항]
- **우선순위**: 필수

#### FR-B03: 검증된 국가 법령 DB 전용 추출 엔진 (Closed-loop RAG)
- **설명**: 외부 인터넷 데이터 학습을 차단하고, 국가법령정보센터 및 경찰청 단속지침 DB 내에서만 정보를 탐색·추출
- **목적**: AI 환각 및 오답 위험을 근본적으로 방지
- **데이터 소스**: 국가법령정보센터, 경찰청 단속지침 DB
- **우선순위**: 필수

#### FR-B04: 현장 상황 자연어-법조항 정밀 매칭
- **설명**: 현장의 애매모호한 위반 상황을 자연어로 입력하면 관련 법조항을 정밀 매칭하여 제공
- **입력 예시**: "일반음식점 특수조명 설치 후 손님 춤 허용"
- **출력**: [단속법규], [벌칙], [행정처분], [약어 표기]를 즉시 제공
- **우선순위**: 필수

#### FR-B05: 현장 단속 체크리스트 및 적발 보고서 자동 생성
- **설명**: 위반 유형에 따른 필수 현장 채증 항목 및 진술서 가이드를 제공하고, 적발 보고서 초안을 자동 작성
- **우선순위**: 높음

## 8. 제약사항 및 유의사항

- 1심 판례는 확정력이 없으므로, 항소·상고 여부 및 결과를 배지로 별도 표시
- 법조문 개정 이력 데이터가 없는 판례는 유사도 기준으로만 정렬 (예외 처리)
- 외부 인터넷 데이터 학습을 차단하는 Closed-loop 방식 유지 필수
- 본 시스템은 법률 자문이 아닌 업무 참고 도구로서의 성격을 명시
